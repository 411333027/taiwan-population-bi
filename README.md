# 臺灣各縣市人口年齡結構與扶養比 BI

- 資料來源：內政部戶政司｜各縣市年底三階段年齡人口數、扶養比及老化指數（`縣市三階段人口及扶養比(96).xls`）
- 資料期間：民國 96 年底 至 114 年底（2007～2025），共 19 年

## 目錄

```
raw/                       原始檔（未經修改）
etl/etl_population.py      ETL：19 個工作表 → 一份 CSV
etl/validate_population.py 驗證：和原始檔獨立比對
data/population_by_year.csv ETL 產出
docs/                      BI 網頁（GitHub Pages 從這裡發佈）
```

## 執行

```
uv run etl/etl_population.py
uv run etl/validate_population.py
```

## 資料欄位（data/population_by_year.csv）

| 欄位 | 說明 |
|---|---|
| year, roc_year | 西元年、民國年（年底資料） |
| region | 行政區，舊縣市已對映到現行 22 縣市 |
| level | 全國、省、縣市（畫圖時只用 `縣市`，避免重複計算） |
| raw_region | 原始報表上的名稱；合併的列以 `+` 連接，例如 `臺中市+臺中縣` |
| pop_total, pop_0_14, pop_15_64, pop_65_plus | 人數 |
| pct_0_14, pct_15_64, pct_65_plus | 年齡分配百分比（%） |
| young_dependency_ratio, old_dependency_ratio, dependency_ratio | 扶幼比、扶老比、扶養比（每百位 15～64 歲人口） |
| aging_index | 老化指數（每百位 0～14 歲人口的 65 歲以上人數） |

## 處理過的髒資料

- 每個工作表的表頭（2 列）、空白列、表尾說明（99 年多了縣市改制的 3 行說明）都排除，只保留有人口數的列。
- 區域名稱含全形空白（如 `臺　北　市`），已去除。
- 縣市改制：臺北縣 → 新北市、臺中縣＋臺中市 → 臺中市、臺南縣＋臺南市 → 臺南市、高雄縣＋高雄市 → 高雄市（99 年 12 月 25 日起）；桃園縣 → 桃園市（103 年 12 月 25 日起）。
- 96～98 年『臺灣地區』是區域小計，已排除。

## 驗證

`etl/validate_population.py` 重新讀原始檔，不共用 ETL 程式，共 12 項檢查，包括：每年 22 縣市 × 19 年、縣市加總 = 總計、三個年齡層加總 = 總人口、未合併的列人數與原始檔完全相同、重算的比例與原始檔誤差 < 1e-9。

## 限制說明

- 96～98 年的臺中市、臺南市、高雄市是改制前縣與市的合計，邊界和現在相同；比例與指標由合計人數重算，不是原始報表的數字。
- 省（臺灣省、福建省）不含直轄市，兩省加總不等於全國。
- 皆為年底戶籍登記人口，不是常住人口。
